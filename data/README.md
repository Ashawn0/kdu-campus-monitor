# EcoSense Dataset

The EcoSense dataset is hosted on Zenodo due to its size.

**DOI:** https://doi.org/10.5281/zenodo.19563976

The dataset contains 5,317 records from three deployment sessions (MyRoom, Classroom1402, ClassLab1404) collected in April 2026 in Sokcho, South Korea. See the main README for full column descriptions.
